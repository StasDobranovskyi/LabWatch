# Захвати ЛР3

Сирі UART/VCD для S1, S2 і S3 та їхні маніфести збережені в локальній теці `Lab03/Work` власника: `S1-d7c3-20261030`, `S2-d7-nov01-run02`, `S3-d7-nov01-run01`. Вони стосуються source `d7c3f569` і ELF `fbb10f8e`; не підмінювати ними запуск іншої версії. Умови та результати наведено в [базовій лінії](../../baseline-lab4.md).

Для основного S3 logic analyzer: PA1 — цифровий PIR proxy, PA6 — IMU, PA7 — журнал, PA10 — початок реакції, PA4 — ADC, PA2/PA3 — UART TX/RX, PA5 — LED. Суміщення 55 різних пар із передачею журналу встановлено декодуванням конкретного VCD; генератор і команди детерміновані. Результат не є виміром фізичного PIR або flash erase.

Після нового дозволеного запуску зберігайте raw VCD/UART, хеші ELF і файлів, фактичні команди та часи; перевіряйте покриття VCD і не змішуйте окремі перервані інтервали. Час приходу на хості не є часом МК.
