# Вимірювання ЛР3

Поточні метрики d7 і межі їхнього трактування наведено в [базовій лінії](../baseline-lab4.md) та [реєстрі обмежень](../limitations.md). Власні сирі UART/VCD, маніфести хешів, журнали збірок і host-тестів зберігаються у локальній теці `Lab03/Work` власника. Вони отримані для source fingerprint `d7c3f569`, ELF `fbb10f8e`; не переносяться з іншого проєкту. Хостовий fake та Wokwi є різними рівнями доказів.

Відтворення перевірок: `make build`, `make test`, `make sanitize`, `make test-linux`, `make coverage`. `tools/stamp.py` вбудовує поточний Git base та хеш вхідних файлів: після зміни HEAD новий ELF може відрізнятися від виміряного. Не називати його виміряним лише на підставі успішної збірки.
